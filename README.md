# Arithmetic limiting laws over shifted primes

**[Open the interactive companion](https://crypto-vipin.github.io/arithmetic-limiting-laws/)** · [Monograph on arXiv](https://arxiv.org/abs/2603.11196) · [PDF](https://arxiv.org/pdf/2603.11196)

Interactive companion to *Arithmetic limiting laws over shifted primes: Hausdorff dimension zero, Fourier decay, and absolute continuity* by Vipin Singh Sehrawat.

The companion presents selected results through interactive calculations, diagrams, and searchable references. It distinguishes proved results, conjectures, open questions, numerical evaluations, and schematic illustrations. Complete statements, hypotheses, and proofs are in the monograph.

## Viewing locally

Download or clone this repository, then open `index.html` in a browser, keeping the `katex/` directory alongside it. No installation is required. Enable JavaScript for interactive controls and generated plots. The mathematical expressions are already rendered.

See the repository's license file for licensing terms. The bundled KaTeX assets retain their accompanying license in `katex/LICENSE`.
